# 🎬 Movie Rating Prediction

##  Project Overview
This project predicts movie ratings using Machine Learning based on movie features such as Genre, Director, Actors, Duration, and Votes.

##  Dataset
The dataset contains:
- Genre
- Director
- Actor 1
- Actor 2
- Actor 3
- Duration
- Votes
- Rating

##  Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Workflow
- Data Cleaning
- Handling Missing Values
- Feature Encoding
- Model Training
- Model Evaluation
- Prediction
