# 🌸 Iris Flower Classification

## 📌 Project Overview
This project classifies Iris flowers into three different species using Machine Learning based on the flower's measurements.

The three species are:
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 📂 Dataset
The dataset contains the following features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target:
- Species
